# Reporting a security problem

If you find a security problem in anything DebugSwift runs (debugswift.com, the free tools, DuctForge or Debnest), please email **hello@debugswift.com** with "Security" in the subject.

Please don't open a public issue for it. Include what you found, where, and how to reproduce it. We'll reply, fix it, and credit you if you'd like.
